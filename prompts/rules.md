# Правила формирования протокола

1. Формат: [Название] ~ [ОПИСАНИЕ] ~ [ЗАКЛЮЧЕНИЕ] ~ (опционально) [КЛИНИЧЕСКИЕ ДАННЫЕ].
2. Маркеры в начале строк — обязательны:
   - [Название]
   - [ОПИСАНИЕ]
   - [ЗАКЛЮЧЕНИЕ]
   - [КЛИНИЧЕСКИЕ ДАННЫЕ] / [ВОЗМОЖНОЕ ЗАКЛЮЧЕНИЕ]
   - [РЕКОМЕНДАЦИИ] (при необходимости)
3. Заключение всегда присутствует.
4. Клинические данные — отдельный блок, не путать с находками.
5. Язык: русский, медицинская терминология.
