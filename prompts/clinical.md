# Клинические данные и черновое заключение

## Правила
1. Клинические данные (анамнез/жалобы) — НЕ рентген-находки.
2. Их выноси в отдельный блок «КЛИНИЧЕСКИЕ ДАННЫЕ (анамнез/жалобы)».
3. При наличии клиники, которая может объяснить находки или при отсутствии
   однозначной рентген-картины — добавь блок
   «ВОЗМОЖНОЕ ЗАКЛЮЧЕНИЕ (черновик, требует клинической верификации)».
4. Основное «ЗАКЛЮЧЕНИЕ» — всегда формируй по фактическим находкам.
5. Черновое заключение явно помечай и не смешивай с основным.
6. Не выдумывай клинику. Если её нет в диктовке — не добавляй.
